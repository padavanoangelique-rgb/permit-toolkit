How Sizes Are Calculated

Perimeter shim: 3/8" gap on each side deducted from the total opening before allocating to units.

Mullion: 1-1/4" default structural mullion width. Adjustable input above. This is deducted from the total unit width when 2+ units share a mullion.

Rounding: Individual unit widths are rounded down to the nearest 1/8" for practical ordering. Any remainder is absorbed into the shim gap.

Field Notes

DP considerations: Larger single fixed windows need higher design pressure. Splitting one large opening into two mulled units often reduces the DP requirement per unit — but the mullion itself must be engineered for the combined load.

Egress: If any unit in the configuration is intended for a sleeping room, that specific unit's clear opening must meet FBC/IRC R310 minimums. Cross-check with the Egress Opening Calculator.

HVHZ: Mullion type and anchor spacing shown on the NOA must be followed exactly — no substitutions between manufacturers.
