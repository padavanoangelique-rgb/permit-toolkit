01 Windows & Doors

60-Second Site Check

Walk a sold window, door, or patio job in about a minute. Tap through field capture, documents, and HOA status. Get production flags and a one-page PDF before the job moves to product or permit-prep.

How to use it
  1. Choose Windows / Doors, Patio Enclosure, or Both, then the property type.
  2. Tap yes/no on measurements, rooms, photos, signed application, and HOA. Condo and patio questions appear only when they apply.
  3. Read the status and next actions. Save or print the PDF. No email required to see the result.
Run site check →
02 Windows & Doors

Window Wall Designer

Lay out units, bucks, and mullions in one opening. The opening stays fixed. Units reflow when you split or drag. Print a shop drawing with sizes in inches.

How to use it
  1. Type the opening in inches (120) or feet-inches (10'-0"). Drawing and PDF always print inches.
  2. Click the pocket to place a unit. Split vertical or horizontal, then drag the mullion for uneven fills (6' over 4' in a 10' hole).
  3. Click a mullion to set 1x4 or 2x4 on that bar only. Pick the unit type, then print / save PDF.
Open designer →
03 Any Trade

Photo Report

Build a numbered photo log on the job. Each shot gets a room and a note. Print a labeled PDF for the file, the HOA, or the permit office.

How to use it
  1. Enter a job name. Use Camera on a phone or Library for existing shots.
  2. Add room location and a short note. Photos number themselves in order.
  3. Reorder if needed, then print / save the PDF. One photo per page with the label.

05 Windows & Doors

Rough Opening Calculator

Convert between unit size, rough opening, and masonry opening. Shim gap and tolerance are in the math so the takeoff matches the hole in the wall.

How to use it
  1. Pick the direction: unit size → rough opening, or the reverse.
  2. Enter the known width and height, plus shim gap.
  3. Use the RO and masonry opening on the order and the field measure.
Open calculator →
06 Windows & Doors

Design Pressure Estimator

Ballpark the components-and-cladding DP an opening needs (ASCE 7 method). Use it to short-list product — not as a sealed calculation.

How to use it
  1. Enter basic wind speed, exposure, and mean roof height.
  2. Enter opening size and zone (corner vs interior wall).
  3. Compare the estimate to the NOA DP. A PE still stamps the permit calc.
Open estimator →
07 Energy

Energy Code Check (U & SHGC)

Check a product’s U-factor and SHGC against the 2023 FBC Energy Conservation prescriptive path and ENERGY STAR for the climate zone.

How to use it
  1. Set climate zone / HVHZ for the job.
  2. Enter the product U-factor and SHGC from the NFRC or NOA.
  3. Read pass/fail on prescriptive code and ENERGY STAR eligibility.
Open energy check →
08 Code

Egress Opening Calculator

See how Single Hung, Casement, and Horizontal Roller compare for FBC / IRC R310 emergency escape. Net clear varies by manufacturer — confirm the chart.

How to use it
  1. Enter nominal unit width and height.
  2. Compare the three operating types for net clear opening.
  3. Confirm the winner against that product’s tested egress chart before you spec a bedroom.
